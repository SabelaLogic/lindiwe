# Lindiwe

Static site for the Lindiwe project under SabelaLogic.

## Deployment
Designed for Cloudflare Pages Direct Upload.

1. Unzip or clone this repo.
2. Deploy the folder containing `index.html` (and any PDFs) via Cloudflare Pages → Direct Upload.
3. No build command required.

Expected pages: Home, Words, Balm, Meat, Bench, Plan.
